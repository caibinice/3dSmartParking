## 验证边界与运维

- 路径/设施/预留与收费为演示配置，不是现场测绘或医院现行制度。模型实例数与 300 泊位业务统计口径分开。
- 连续语音测试覆盖事件状态机和显式唤醒打断；识别依赖实际浏览器服务，未将自动注入语句当作真人唤醒正确率。
- AG-UI 适配覆盖当前服务产生的事件子集；不声明支持全部渲染事件族。
- 02:15 Asia/Shanghai 的原进程内调度只做数据库四类汇总，无 LLM 花费；业务台可读取 `/report-jobs` 状态。
- npm audit 的既有 Angular CLI 开发依赖链仍报告 `http-cache-semantics` GHSA-ch52-4w7c-c8xp；当前上游修复尚未发布。生产静态包不携带 CLI 开发服务，不用强制降级 CLI 掩盖结果。
